# turn-panel

[English](README.md) · **한국어**

세션의 요청과 완료 보고를 패널에 한 묶음으로 보여 주는 Claude Code 모드다. 턴이 도는 동안의 진행 상황과, 근거와 보낼 글이 붙은 다음 작업 제안 3개까지 함께 보인다.

Claude Code 세션을 여러 개 오가며 쓰면, 돌아온 세션에서 무엇을 시켰고 무엇이 끝났는지 대화를 거슬러 올라가 읽게 된다. turn-panel은 그것을 패널에 모아 둔다. 무엇을 요청했는지, 무엇이 끝났는지(또는 지금 무엇을 하는 중인지), 다음에 무엇을 하면 되는지를 보고 키보드로 고른다.

## 기능

- **요청과 보고를 한 묶음으로**: 그 턴의 요청(줄바꿈 그대로), 상태(완료 · 3분 전 · 2분 14초), 최종 보고
- **진행 상황**: 턴이 도는 동안 지금 하는 일(파일 읽는 중, 명령 실행 중 …), 경과 시간, 할 일 목록이 있으면 체크리스트
- **근거 붙은 다음 작업**: 제안 최대 3개. 짧은 문구, 근거, 실제로 보낼 글을 모두 보인다
- **입력란의 첫 제안**: 턴이 끝나면 첫 제안이 입력란에 흐린 글씨로 뜬다. `Tab`으로 받아 읽어 보고 `Enter`로 보낸다
- **답 고르기**: Claude가 질문으로 끝내면 제안이 내가 할 답들(예: "B안으로", "문서 없이 바로")이 된다. 짧은 답을 키 하나로 한다
- **다시 열어도 남는 기록**: 세션을 다시 열면(`--resume`, `--continue`, cmux 세션 복원) Claude Code가 저장해 둔 대화에서 최근 턴을 되살린다
- **링크**: 보고의 주소, `#123`, `owner/repo#123`을 누를 수 있는 링크로 바꾼다. 주소는 cmux 브라우저 칸에서 연다. 보고에 적힌 파일은 **링크** 상자에 모아 편집기에서 그 줄로 연다
- **패널에 맞는 표**: 보고의 마크다운 표를 패널 폭에 맞춰 그리고, 긴 칸은 그 칸 안에서 줄을 바꾼다
- **바뀐 파일**: 그 턴에서 고치거나 만든 파일. 하위 에이전트가 고친 것도 포함한다
- **지난 턴**: 세션의 최근 20턴을 `p`·`n`으로 넘겨 본다
- **키보드 중심**: `ctrl+x tab`으로 패널에 가서 `1`~`3`으로 고르고 `Esc`로 돌아온다
- **원격으로 볼 때**: 데스크톱 앱·웹·모바일로 세션을 보면 링크는 지금 보고 있는 기기에서 열린다

## 필요한 것

- Claude Code **2.1.296** 이상, 터미널에서 연 세션. 모드 API가 얼리 액세스라 이 버전에서 만들고 확인했다.
- macOS. 링크와 파일을 여는 데 `open`을 쓴다.
- 있으면 좋은 것: cmux 터미널(주소를 워크스페이스 안의 브라우저 칸에서 연다), 편집기의 명령 줄 실행기(`webstorm`, `code`, `cursor`). 없어도 패널은 그대로 동작한다.

## 설치

터미널에서 연 Claude Code 세션의 입력란에 친다.

```
/plugin install turn-panel --marketplace JunH-K/claude-turn-panel
```

`Add marketplace?`에 `y`로 답하고, 범위는 사용자(user)를 고른다. 그 세션에서 바로 동작하고 새로 여는 세션에도 적용된다. 이미 떠 있던 세션은 다시 켜야 반영된다.

셸에서 해도 된다.

```bash
claude plugin marketplace add JunH-K/claude-turn-panel
claude plugin install turn-panel@claude-turn-panel
```

`1 userConfig option not yet set`은 편집기 옵션을 고르지 않았다는 뜻일 뿐이다. 기본값(`webstorm`)으로 동작한다.

`claude plugin list`에서 `turn-panel@claude-turn-panel`이 `enabled`로 나오거나, 세션에서 `/turn-panel`을 쳐서 패널이 열리면 된다.

## 쓰는 법

턴이 시작하거나 끝나면 패널이 스스로 열린다. 터미널이 좁아 열리지 못하면 상태 줄에 `/turn-panel` 안내가 뜬다.

### 명령

| 명령 | 하는 일 |
| --- | --- |
| `/turn-panel` | 패널을 키보드 초점과 함께 연다. 열려 있으면 닫는다. 닫아 두면 다시 열 때까지 스스로 열리지 않는다. |
| `/turn-panel off` | 이 세션에서 모드를 끈다. 패널이 열리지 않고 제안 블록도 쓰지 않는다. |
| `/turn-panel on` | 다시 켠다. |

### 키

입력란과 패널을 오가는 키는 Claude Code의 기본 키다.

| 키 | 하는 일 |
| --- | --- |
| `Tab` (입력란에서) | 빈 입력란에 흐리게 뜬 첫 제안을 받는다 |
| `ctrl+x` 다음 `tab` | 입력란에서 패널로. `ctrl+x`를 뗀 뒤 3초 안에 `tab`을 누른다. |
| `Esc` | 패널에서 입력란으로 |
| `ctrl+x` 다음 `x` | 패널 닫기 (패널에 초점이 있을 때) |
| `ctrl+x` 다음 `←` / `→` | 패널 키우기 / 줄이기. 맞춘 폭은 기억된다. |

패널에 초점이 있을 때 쓰는 키다.

| 키 | 하는 일 |
| --- | --- |
| `1`~`3` | 그 제안을 다음 요청으로 바로 보낸다. `/`로 시작하는 제안은 입력란에 채우기만 한다(Enter로 실행). |
| `e` 다음 `1`~`3` | 입력란에 채워서 고친 뒤 보낸다 |
| `p` / `n` | 이전 턴 / 다음 턴 |
| `Tab`, 방향키, `Enter` | 링크나 바뀐 파일로 옮겨 가서 연다 |

## 옵션

`/config`에서 바꾼다.

| 옵션 | 값 | 기본값 |
| --- | --- | --- |
| 파일을 여는 편집기 (`editor`) | `webstorm`, `vscode`, `cursor`, `system` | `webstorm` |

`webstorm`, `vscode`, `cursor`는 각자의 명령 줄 실행기를 쓴다. 실행기가 없거나 `system`이면 맥의 기본 **글 편집기**(`open -t`)로 연다. 파일의 기본 앱으로는 열지 않으므로, 파일을 연다고 스크립트가 실행되지 않는다.

## 동작 방식

모드는 시스템 프롬프트에 구역 하나를 더해, Claude가 작업 보고 끝에 아래 블록을 쓰게 한다.

````
```next
짧은 문구 | 근거 한 문장 => 그대로 보낼 요청 글
```
````

Claude가 질문으로 끝낼 때는 각 줄이 내가 할 답이 된다. 패널이 이 블록을 읽어 **다음 작업** 상자로 옮기고, 첫 줄을 입력란의 흐린 제안으로 띄우고, 대화 화면에서는 블록을 빼고 그린다. 저장된 답변에는 그대로 남아 `ctrl+o`로 펼치면 보인다. 블록을 가리는 것은 패널이 대신 보여 줄 수 있을 때뿐이다. 패널이 닫혀 있거나 블록의 형식이 어긋나면 대화 화면에 그대로 보인다.

`/turn-panel off`를 하면 다음 턴부터 구역이 빠지고, Claude Code가 스스로 띄우는 흐린 제안은 그대로 둔다. 화면 없는 실행(`claude -p`, SDK)에서는 아무 일도 하지 않는다.

세션을 다시 열면 Claude Code가 저장한 대화(`$.session.messages()`)에서 최근 20턴을 되살린다. 되살린 턴은 걸린 시간을 모르므로 "이전 실행"으로 보인다.

## 안전

제안은 모델이 쓰고, 모델은 읽은 글(파일, 웹 페이지, 도구 출력)에 흔들릴 수 있다. 그래서 무엇이든 사용자가 먼저 보고 나서야 움직이게 했다.

- 제안이 보낼 글 전체를 키를 누르기 전에 보인다.
- 슬래시 명령 제안은 바로 실행하지 않는다. 입력란에 채우고 Enter를 기다린다. 입력란의 흐린 제안으로도 띄우지 않는다.
- 입력란의 흐린 제안은 받아도 입력란에 채워질 뿐이다. Enter를 치기 전에는 아무것도 보내지 않는다.
- 답 고르기에는 되돌리기 어려운 일(push, 배포, 삭제, 외부 전송)을 승인하는 답을 넣지 않는다. 그런 답은 직접 친다.
- 300자를 넘거나, `!`로 시작하거나, 보이지 않는 문자·속이는 문자가 든 제안은 버린다.
- 제안이 바뀐 뒤 1.5초 안의 누름은 받지 않는다.
- 보고의 파일 경로는 터미널 링크로 만들지 않는다. ⌘-클릭하면 파일의 기본 앱으로 열리기 때문이다. 파일은 링크·바뀐 파일 상자에서만, 편집기나 `open -t`로 연다. Claude가 쓴 `file:` 주소는 마크다운을 어떻게 썼든 링크가 되지 않게 끊는다.
- Claude가 쓴 링크는 누르는 글자가 언제나 실제 주소가 되게 다시 쓴다: `[github.com/…](https://other.example)`은 `github.com/… (other.example)`로 보인다. 검사를 통과하지 못한 주소(웹이 아닌 주소, `user@host`)는 글로 풀고, 참조 정의는 받지 않는다.
- 경로가 실제로 있는지는 세션 폴더나 홈 폴더 안에서만, 폴더를 하나씩 내려가며 바로가기를 따라가지 않고 확인한다. `/net/<호스트>/…` 같은 경로는 들여다보기만 해도 맥이 네트워크 마운트를 시도할 수 있다.
- IDE로 여는 것은 세션 폴더 안의 파일뿐이다(바로가기는 실제 경로로 풀어서 본다). 밖의 파일은 글 편집기로 연다. IDE는 파일과 함께 그 프로젝트의 설정(실행 구성, 작업)까지 불러오기 때문이다.
- 명령은 셸을 거치지 않고, 주소와 경로를 검사한 뒤에 실행한다. 실행하는 명령은 `git remote get-url`, `cmux`, 편집기 실행기, `open`뿐이다.
- 턴 기록은 그 세션의 메모리에 두고, 다시 열 때는 Claude Code가 저장한 대화에서 되살린다. 모드는 파일을 쓰지 않고 밖으로 보내지 않는다.

## 갱신과 지우기

```bash
# 갱신 (Claude Code를 다시 켜야 반영된다)
claude plugin marketplace update claude-turn-panel
claude plugin update turn-panel@claude-turn-panel

# 끄기 (다시 켜려면 enable)
claude plugin disable turn-panel@claude-turn-panel

# 지우기
claude plugin uninstall turn-panel@claude-turn-panel
claude plugin marketplace remove claude-turn-panel
```

설치하지 않고 써 보기:

```bash
git clone https://github.com/JunH-K/claude-turn-panel.git
claude --plugin-dir ./claude-turn-panel
```

```bash
claude --plugin-dir .       # 이 폴더의 모드를 그 세션에만 불러온다. 고치면 다시 불러온다
claude plugin validate .    # 선언과 훅을 엔진이 읽는 대로 검사한다
claude plugin test .        # tests/*.test.ts 를 돌린다
tsc -p .                    # 타입 검사. 엔진이 .claude-plugin/types 를 깐 뒤에 돌린다
```
